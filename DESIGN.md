# Design System: TrustBridge Market
**Project ID:** TBD

## 1. Visual Theme & Atmosphere
Professional, secure, and reliable. The atmosphere is modern, clean, and trust-focused, using a card-based layout with clear hierarchy to ensure ease of navigation and a feeling of safety during transactions.

## 2. Color Palette & Roles
* **Primary Blue** (#137fec): Used for primary actions, branding, and active states.
* **Pure White** (#ffffff): Secondary color, used as a clean background for content areas.
* **Light Gray Accent** (#f5f7fa): Used for backgrounds, subtle borders, and structural separation.
* **Success Green** (#22c55e): Confirms successful actions, verified badges, and escrow completion.
* **Warning Orange** (#f59e0b): Alerts users to pending actions or important, non-critical warnings.
* **Error Red** (#ef4444): Indicates destructive actions, errors, or security risks.

## 3. Typography Rules
* **Font Family:** Manrope
* **Headings:** Bold weight, used for page titles, section headers, and card titles.
* **Body:** Regular weight, used for descriptive text, transaction details, and general content.

## 4. Component Stylings
* **Buttons:** Subtly rounded corners, prominent solid fills for primary actions using Primary Blue. Clear CTA styling with smooth hover micro-interactions.
* **Cards/Containers:** Subtly rounded corners, mostly White background on Light Gray Accent page background, with whisper-soft diffused shadows to create slight depth. Contains hover effects for interactivity.
* **Inputs/Forms:** Clean strokes with subtle borders on active focus, easy to read with minimal clutter.

## 5. Layout Principles
Desktop-first approach but optimized for tablet and mobile responsive design. Uses a sticky top navigation bar with a mega menu. Uses a clear grid alignment for the card-based marketplace layout with a filter sidebar.
